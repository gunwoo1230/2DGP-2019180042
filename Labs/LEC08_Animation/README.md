# Drill #8 — 애니메이션 뷰어

소닉 스프라이트 시트에서 4종의 애니메이션을 잘라 화면 중앙에서 차례로 재생한다.
각 애니메이션은 5회 반복 → 1초 정지 → 다음 애니메이션 순으로 무한 반복된다.

## 실행 방법

```
cd Labs/LEC08_Animation
py animation_viewer.py
```

- Python 3.13 + pico2d
- ESC 키 또는 창 닫기로 종료
- 다른 폴더에서 실행해도 스크립트 옆의 리소스를 찾는다.
  리소스가 없거나 손상되면 어떤 파일이 문제인지 알려주고 종료한다.

## 사용 리소스

| 파일 | 크기 | 용도 |
|---|---|---|
| `sonic-sprite.png` | 399×525, 투명 배경 | 캐릭터 스프라이트 시트 (Sprites by Zeper the hedgehog, edits by ballal) |
| `TUK_GROUND.png` | 1280×1024 | 배경. 800×640 창에 꽉 차게 그림 (같은 5:4 비율) |
| `grass.png` | 802×62 | 화면 하단 발판 |

## 요구사항 대응

| 요구사항 | 구현 |
|---|---|
| 애니메이션 4종 이상 | `run`, `roll`, `balance`, `dizzy` |
| 화면 중앙에서 재생 | 가로 중앙 x=400, 발은 발판 윗면 `GROUND_Y = 52`에 고정 |
| 확대 (화면 절반 이상) | 애니메이션마다 가장 큰 프레임이 340px (창 높이 640의 53%) |
| 5회 반복 후 1초 정지 | `REPEAT_COUNT = 5`, `PAUSE_TIME = 1.0`. 정지 중에는 첫 프레임 표시 |
| 모든 애니메이션 무한 반복 | 마지막(dizzy) 다음은 다시 처음(run) |

## 보너스 1 — 프레임마다 크기가 다른 Sprite Sheet

이 시트는 격자로 정렬되어 있지 않아 프레임마다 위치와 크기가 모두 다르다.

1. **프레임 좌표 추출**: 시트의 알파(>16)를 기준으로 행 → 프레임 순서로 자동 분할하고,
   각 프레임을 실제 픽셀 경계까지 타이트하게 잘랐다. 그 결과를 소스에 `(x, y, w, h)` 표로 넣었다.
2. **개별 관리**: `FRAME_WIDTH` 같은 고정 크기 상수는 없다. 프레임마다 자기 `(x, y, w, h)`로 그린다.
   예) balance는 폭 20~40, 높이 27~45로 프레임마다 다르다.
3. **좌표 변환**: 시트 좌표는 좌상단 기준이고 pico2d는 좌하단 기준이다. 그래서
   `bottom = sheet.h - y - h`로 바꿔 `clip_draw(x, bottom, w, h, ...)`를 호출한다.
4. **하단 기준 정렬**: 높이가 다른 프레임을 중심 기준으로 그리면 발이 뜨거나 파묻힌다.
   그래서 모든 프레임의 아래 변이 `GROUND_Y`에 오도록 중심을 `GROUND_Y + h/2`로 잡는다.
5. **배율 고정**: 배율은 애니메이션마다 `340 / 그 애니메이션의 최대 프레임 높이`로 한 번만 계산한다.
   그 애니메이션의 모든 프레임에 같은 배율을 쓰므로, 프레임 크기가 달라도 캐릭터가 떨리지 않는다.

| 애니메이션 | 프레임 크기 (w × h) | 배율 |
|---|---|---|
| run | 24~37 × 35~38 | 8.95 |
| roll | 29~30 × 27 | 12.59 |
| balance | 20~40 × 27~45 | 7.56 |
| dizzy | 23~34 × 39~43 | 7.91 |

## 보너스 2 — 애니메이션별로 다른 프레임 수

| 애니메이션 | 프레임 수 | 1회 재생 | 5회 + 정지 |
|---|---|---|---|
| run | 12 | 0.96초 | 5.8초 |
| roll | 6 | 0.48초 | 3.4초 |
| balance | 8 | 0.64초 | 4.2초 |
| dizzy | 4 | 0.32초 | 2.6초 |

- 애니메이션 하나는 프레임 **리스트**다. 프레임 수 상수는 없고, 개수는 항상 `len(frames)`로 구한다.
- 재생은 경과 시간 기준이다. `step = int(경과시간 / FRAME_TIME)`로 지난 프레임 수를 구한다.
  - 현재 프레임은 `step % len(frames)`이다.
  - 반복 횟수는 `step // len(frames)`이다.
  - 정지 시작 시각은 `5 × len(frames) × FRAME_TIME`이다.
- 따라서 프레임 수가 달라도 같은 코드로 정확히 5회씩 반복된다. 새 애니메이션은 `ANIMATIONS`에 프레임 리스트를 추가하기만 하면 된다.

## 코드 구조 (`animation_viewer.py`)

| 이름 | 역할 |
|---|---|
| `RUN_FRAMES` 등, `ANIMATIONS` | 프레임 좌표 데이터와 재생 순서 |
| `Animation` | 프레임 리스트, 애니메이션별 배율, 하단 기준 `draw()` |
| `AnimationPlayer` | 현재 애니메이션·프레임, 5회 반복 → 1초 정지 → 다음 전환 |
| `init` / `handle_events` / `update` / `draw` | 캔버스·리소스 준비, 종료 입력, 재생 갱신, 배경→발판→캐릭터 그리기 |
